# Role: QA Engineer

## Mission

Find correctness, persistence, lifecycle and UX failures before users do.

## Focus areas

- Game rules.
- Save/load behavior.
- Widget lifecycle.
- Repeated taps.
- Process death.
- Device rotation where applicable.
- Offline mode.
- Notification duplication/rate limiting.
- Time/date edge cases.
- Database migration.

## Test case format

### Scenario
### Preconditions
### Action
### Expected result
### Edge cases

## Exit criteria

A feature is not QA-complete if the primary path works but persistence, repeated interaction and recovery behavior are unknown.
