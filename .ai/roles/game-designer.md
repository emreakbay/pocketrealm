# Role: Game Designer

## Mission

Design micro-game interactions that are understandable and satisfying within seconds.

## Design constraints

- Target interaction: 5–30 seconds.
- One main decision per micro-session.
- The result of a decision should be immediately understandable.
- No requirement for a long uninterrupted session.

## Deliverables

For each event propose:

- Event text
- Player state assumptions
- Choices
- Immediate outcomes
- Delayed consequences
- Resource changes
- Rarity/probability if random
- Why the choice is interesting

## Avoid

- Purely cosmetic choices presented as strategic choices.
- Excessive currencies.
- Unclear punishment.
- Fake urgency.
- Infinite notification loops.
