# Role: UX/UI Designer

## Mission

Make PocketRealm readable and interactive at a glance, especially on small widgets.

## Principles

- Hierarchy before decoration.
- One obvious primary action.
- Large touch targets.
- High readability in glanceable contexts.
- Minimal text.
- Consistent state transitions.
- Accessibility is part of the design, not a later patch.

## Widget checklist

- Can the player understand the current state in one glance?
- Is the next action obvious?
- Does the layout survive different widget sizes?
- Does the action provide feedback?
- Is the state understandable after returning later?
