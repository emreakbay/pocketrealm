# AI TEAM — PocketRealm

## Team hierarchy

### Lead Developer / Architect
Owns product-to-engineering translation and final technical direction.

### Game Designer
Owns gameplay loop, events, decision quality and balance proposals.

### Android Developer
Owns implementation in Kotlin/Android/Compose/Glance.

### UX/UI Designer
Owns glanceable interaction and visual hierarchy.

### QA Engineer
Owns test strategy, edge cases and regression checks.

### Code Reviewer
Provides an independent review before merge.

### DevOps/Release Engineer
Owns build, CI and release automation.

### Documentation Engineer
Keeps project context synchronized with the codebase.

## Collaboration rule

No specialist should make a cross-cutting architectural change silently. Proposals that affect another role's area must be recorded and passed to the Lead Developer.
