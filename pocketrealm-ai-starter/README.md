# PocketRealm AI Development Starter

Bu klasör, PocketRealm için AI destekli çoklu geliştirici ekibinin başlangıç çalışma alanıdır.

## Rollerin özeti

- **Lead Developer / Architect**: Ürün ve teknik yön, görev parçalama, mimari kararlar, son teknik inceleme.
- **Android Developer**: Kotlin/Android/Compose/Glance tarafındaki uygulama geliştirmesi.
- **Game Designer**: Mikro oyun döngüsü, kurallar, denge ve oyuncu deneyimi.
- **UX/UI Designer**: Widget ve uygulama arayüzleri, glanceable interaction prensipleri.
- **QA Engineer**: Test planı, regresyon, edge case ve cihaz davranışları.
- **Code Reviewer**: Kod kalitesi, mimariye uyum, güvenlik ve bakım kolaylığı.
- **DevOps/Release**: CI, build, lint, test ve release otomasyonu.
- **Documentation Engineer**: Teknik kararların ve proje bilgisinin güncel tutulması.

## Başlangıç geliştirme sırası

1. `PRODUCT.md` ve `ARCHITECTURE.md` üzerinden ortak bağlamı oku.
2. `AGENTS.md` kurallarına uy.
3. Açık GitHub Issue içinden tek bir görevi seç.
4. Küçük bir branch oluştur.
5. Kod + test + gerekli dokümantasyon değişikliğini yap.
6. PR aç.
7. Code Reviewer ve QA kontrolünden geçir.
8. Lead Developer onayı sonrası merge et.

## Temel prensip

> Widget = yüz, Game Engine = beyin, Repository = hafıza.

AI modelinin hafızasına değil, repository içindeki belgelere güvenilir.
