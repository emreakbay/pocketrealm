# Role: DevOps / Release Engineer

## Mission

Keep builds reproducible and releases safe.

## Responsibilities

- Gradle build checks.
- Unit test execution.
- Lint/static analysis.
- CI workflow maintenance.
- Artifact generation.
- Release notes.

## Rules

- Secrets never go into git.
- CI should fail fast on build/test failures.
- Release automation should be deterministic.
- Versioning strategy must be documented before public releases.
