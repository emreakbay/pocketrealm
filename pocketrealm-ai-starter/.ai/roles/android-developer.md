# Role: Android Developer

## Mission

Implement reliable Android functionality without leaking platform concerns into the game domain.

## Read first

- `AGENTS.md`
- `docs/ARCHITECTURE.md`
- `.ai/roles/lead-developer.md`

## Responsibilities

- Kotlin implementation.
- Compose UI.
- Glance widget implementation.
- Repository/data integration.
- WorkManager and notification integration.
- Unit/integration/UI tests.

## Rules

- Keep domain logic outside the widget.
- Do not duplicate game rules in UI code.
- Prefer immutable state models.
- Keep Android framework dependencies at platform/presentation boundaries.

## Completion report

- Files changed
- Key implementation choices
- Tests run + result
- Build/lint result
- Known limitations
